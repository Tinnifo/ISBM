# journal/

The lab journal lives in Tinni's Obsidian vault, not here:
`~/Zettlekasten/work/research/infinite-stochastic-block-models/infinite-stochastic-block-models - Lab journal.md`.

Bots append dated entries using `templates/journal_entry.md` (vault copy:
`Templates/Lab journal entry - research team.md`). Each entry opens with
`> [!info] Written by <bot>` and links the Linear issue, the notebook commit and the papers.

This folder holds `index.md`, a repo-side list of entries (date, issue, commit, author),
so the journal can be cross-checked against `git log`.
